## The load-bearing redundancy — do not "simplify" this

Task 6's implementer disclosed a mutation that did NOT fail: removing main's own
`dismissThumbnail` call left the test green, because the renderer also closes the
panel on trash. It looks like dead redundancy. It is not. **Main's call is the
only one that removes the panel SYNCHRONOUSLY**, and that is exactly what makes
the quit warning correct — the renderer's `{kind:"done"}` is an async round trip
and would leave a window in which the dialog counts a take already promised for
deletion, and Save All would then resurrect it into the library. Item 3 above
adds the test that fences this. Until it lands, only a comment holds it.
