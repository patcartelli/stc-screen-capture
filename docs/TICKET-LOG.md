| STC-376 | **CI compiled and RAN clean on the first real `swiftc` pass — DID NOT need STC-370's 2 rounds of iteration.** Found and diagnosed live while verifying STC-370 on hardware, then fixed here. `App.shutdown()`'s guard used to be `state == .recording \|\| state == .starting`, so a `stop` command already in flight (`state == .stopping`, teardown running async — `writeSidecars()`/`writer.finishWriting()` not yet done) fell through neither branch when a `quit`/stdin-close shutdown landed right behind it: the old code sent `bye` and called `exit()` immediately, before that teardown had written anything.
